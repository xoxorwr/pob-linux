# Path of Building for Linux


# Dependencies

- glfw
- zlib
- libwebp
- libcurl

# How to Use:

```
git clone https://github.com/PathOfBuildingCommunity/PathOfBuilding.git
cd PathOfBuilding
git clone --recursive https://github.com/xoxorwr/pob-linux.git runtime-linux
make -C runtime-linux/
./runtime-linux/pob
```
